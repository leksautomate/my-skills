# Almighty UGC Factory

A single, self-contained UGC skills package — prompts only.

**To use it (any AI, any machine):** copy this whole folder, and give
the AI the `SKILL.md` at the top of the folder as the entry point. It
will ask whether you want a talking-head script or a multi-shot video
with camera direction, then follow the matching sub-skill — both are
inside this folder:

- `ai-ugc-video-production/` — Route A: talking-head scripts
  (templates, product acting, subtitle styles)
- `ugc-content-factory/` — Route B: multi-shot, director-first video
  prompts (creative brief → beat sheet → synced script → Kling prompts)

No generation, no API keys, no credits — it writes the prompts and
scripts only.
